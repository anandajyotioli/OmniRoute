- **fix(cli):** `omniroute skills skillssh install <url>` now works. It posted `{ url }`, which the install route has never accepted, so every install failed with a 400. The command accepts `https://skills.sh/<owner>/<repo>/<skill>` or `<owner>/<repo>/<skill>`, sends the `{ name, description, source, skillId }` the route validates, rejects anything else before calling the API, and prints the server's error message when the install is refused.
